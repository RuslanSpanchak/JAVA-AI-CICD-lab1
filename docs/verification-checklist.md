# Чекліст перевірки перед здачею

Позначай пункти лише після фактичного виконання на своєму комп'ютері або GitHub.

- [ ] `java -version` показує JDK 21.
- [ ] `mvn -version` завершується успішно.
- [ ] `mvn -B clean verify` завершується кодом 0.
- [ ] У звіті Surefire всі тести пройшли; кількість зафіксовано: ______.
- [ ] Створено `target/text-analyzer-1.0.0.jar`.
- [ ] Команда `java -jar target/text-analyzer-1.0.0.jar "Hello world"` показує 2 слова, 11 символів і 1 рядок.
- [ ] Переглянуто diff усіх змін, які запропонував AI.
- [ ] Репозиторій опубліковано на GitHub, якщо це вимагається викладачем.
- [ ] У вкладці Actions є успішні job-и для Linux, Windows і macOS.
- [ ] На захисті можу пояснити manifest, skills, commands, orchestrator, локальні тести й CI.

**Важливо:** не позначай останні кроки як виконані лише тому, що відповідні файли існують у репозиторії.
